How to Play Memory Box

1. Study the number and emoji pairs for 10 seconds.

2. When the pieces drop into the box, spin the wheel to reveal a pair.

3. Tap the empty square that held that pair. A correct match stays revealed and leaves the wheel.

4. Find all but one pair to win. Too many wrong picks end the game.
