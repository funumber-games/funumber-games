How to Play Shape Escape

1. Spin the wheel to see which shape wants to get out.

2. Tap a window with the same shape. Some 3D shapes fit more than one window.

3. A correct window opens and the shape escapes. Three mistakes in a row end the game.

4. Free every shape to win!
