BUNDLE DELIVERY

How to play

  1. Listen to the orderThe customer asks for a two-digit number of colour pencils.
  2. Pack tens and onesEach box holds ten pencils. Each loose pencil is one.
  3. Fix any itemTap a packed bundle or pencil to return it before delivery.
  4. Deliver the orderUse Deliver when the Tens and Ones compartments are ready.

There is no timer or penalty. Use Hint or Hear again whenever you need help.
